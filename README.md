# Sales Analysis System

A web-based Sales Analysis System designed to manage, analyze, and visualize sales records efficiently. The system allows users to record sales data, search and filter records, and analyze sales performance based on different time periods and customer categories.

## Features

* Add and manage sales records
* Search sales records
* Filter sales by date and product
* Analyze daily, monthly, quarterly, and yearly sales
* Analyze festive sales such as Holi, Diwali, Eid, and Christmas
* Categorize customers based on buyer type
* View sales statistics and reports
* Generate sales analysis for better decision-making
* Simple and user-friendly dashboard

## Customer Categories

The system supports different customer categories:

* Boy
* Girl
* Man
* Woman
* Child
* Old Age

## Sales Analysis

Sales data can be analyzed according to:

* Date
* Month
* Quarter
* Year
* Festival

## Technology Stack

* HTML5
* CSS3
* JavaScript
* Java
* MySQL

## Project Structure

The project is organized into separate frontend, backend, and database components to maintain a structured and manageable development environment.

## Database

MySQL is used for storing and managing sales records, customer information, product details, and other required system data.

## Getting Started

### Prerequisites

Make sure the following software is installed:

* Java
* MySQL
* VS Code
* Git

### Run the Project

1. Clone the repository.

```bash
git clone https://github.com/easha1708/Sales_Analysis_System.git
```

2. Open the project folder in VS Code.

3. Configure the MySQL database according to the project database configuration.

4. Run the Java backend/application.

5. Open the frontend in a browser or using a local development server.

## Purpose

The main purpose of the Sales Analysis System is to provide an organized platform for recording, managing, searching, and analyzing sales data. It helps users understand sales patterns and performance through structured reports and analysis.
